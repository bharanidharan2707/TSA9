# AI Voice Assistant

## About

A Python-based voice assistant that understands voice commands and provides spoken responses.

## Features

* Recognize voice commands.
* Respond using speech.
* Tell date and time.
* Open websites.
* Answer simple questions.

## Technologies

* Python
* Speech Recognition
* Text-to-Speech
* NLP

## Run

```bash
pip install -r requirements.txt
python app.py
```
